# 暖棕小屋 · Warm Brown

暖棕小屋是一个美拉德棕色线稿风的烘焙咖啡微信原生小程序，使用 WXML、WXSS、JavaScript 和 JSON 开发。

## 项目介绍

- 猫咪烘焙、云朵蛋糕、小狗咖啡三套首页，可在「我的 → 首页风格」中切换。
- 支持商品分类与搜索、规格选择、购物车、结算，以及店内点单、门店自取、外卖配送和全国邮寄。
- 提供订单查询、模拟支付、会员余额、积分、优惠券和地址管理，数据保存在本地。

支付、储值、会员身份、配送和物流均为本地演示，不会真实扣款或产生实际配送。

## 如何运行

1. 安装并打开微信开发者工具。
2. 从 GitHub 克隆仓库，或选择「Code → Download ZIP」下载并解压源码。
3. 在微信开发者工具中选择「导入项目」，目录选择包含 `project.config.json` 的项目根目录。配置已将 `miniprogramRoot` 指向 `miniprogram/`，无需选择内层目录。
4. 使用自己有权限的小程序 AppID，或开发者工具提供的测试号；选择不使用云服务。
5. 保留配置中的基础库版本 `3.11.3`，点击「编译」。首次启动会生成本地演示数据。
6. 通过底部「首页 / 点单 / 订单 / 我的」体验功能；在「我的 → 首页风格」切换三套首页。

运行小程序无需 `npm install`、构建 npm 或启动后端服务器，页面和图片均随源码提供。

若导入后首页空白，请清除开发者工具的文件与编译缓存后重新编译；无需清除数据缓存。若画面仍停留在旧页面，请在开发者工具设置中启用 GPU 加速并重启工具。
