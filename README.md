# 暖棕小屋 · Warm Brown

烘焙、甜品、咖啡与宠物友好门店的微信原生小程序课程作品。采用 WXML、WXSS、JavaScript、JSON，实现三套首页和可持久化的模拟交易流程；项目不是普通网页或手机外框模型。

## 导入与运行

1. 安装并打开微信开发者工具，选择「导入项目」。
2. 项目目录选择克隆或解压后包含 `project.config.json` 的根目录；本机目录为 **`D:\大\小程序期末`**。配置中的 `miniprogramRoot` 已指向 `miniprogram/`，无需再次选择内层目录。
3. 当前 `project.config.json` 已配置项目所有者的小程序 AppID；其他使用者请改为自己的 AppID 或微信开发者工具提供的测试号。AppID 是应用标识，不包含 AppSecret 或支付密钥。选择不使用云服务。
4. 保留项目配置中的 **`libVersion: "3.11.3"`**，点击「编译」。首次启动自动生成样例数据，默认展示猫咪烘焙首页。
5. 在模拟器中通过底部「首页 / 点单 / 订单 / 我的」操作。推荐先阅读 [3–5 分钟演示步骤](docs/DEMO.md)。

如果导入后仍出现旧版空白首页或 `Component is not found`，清除开发者工具的文件/编译缓存并完整重新编译，无需清除小程序的数据缓存。如果页面路径或标题改变但画面仍停留在旧页，请到「设置 → 通用设置 → 启动设置」启用**使用 GPU 加速模式**并重启工具。此前诊断使用的 `--disable-gpu` 会被工具记入全局设置，之后普通启动也可能继续禁用 GPU。基础库 **3.11.3** 是本次固定复测环境；并无证据证明换库能单独消除此类画布残留。

**运行小程序不需要 `npm install`、构建 npm、生产服务器、地图密钥或支付账号。** 页面和图片全部随源码提供，初始化后可离线演示。首次安装、打开开发者工具本身可能仍需要微信平台连接。

此前游客演示使用的 `touristappid` 不能当作正式发布凭据。真机预览、上传或发布需使用自己拥有的小程序 AppID，并遵循微信平台要求。项目中没有密钥。

本环境使用微信开发者工具 **1.06.2504030 / 基础库 3.11.3**，已通过真实鼠标操作验证三套首页切换、规格弹层、加入购物袋、增减与关闭弹层，并恢复猫咪首页和原有空购物车，见[三套首页截图](artifacts/screenshots/homes-verified.png)及[原生验收报告](artifacts/screenshots/component-runtime-report.json)。组件 WXSS 的非法选择器已修复；**33 项自动测试全部通过**，组件检查与 21 个 WXML、24 个 WXSS 编译通过。原生验收范围见[测试记录](docs/TEST_RECORD.md)，修复说明见[组件修复记录](docs/COMPONENT_FIX.md)。

## 已实现功能

| 模块 | 可操作内容 |
| --- | --- |
| 三套首页 | 猫咪烘焙、云朵蛋糕、小狗咖啡，布局各自独立，风格持久化 |
| 原生导航 | 四项原生 TabBar；原生顶部导航，不绘制手机框、虚假系统栏 |
| 点单 | 5 类、15 个商品，名称搜索、分类、售罄限制、规格加价、数量选择 |
| 购物车 | 同规格合并、不同规格独立，增减删除、确认清空、金额联动 |
| 履约 | 店内点单、门店自取、外卖配送、全国邮寄；不兼容商品须确认处理 |
| 结算 | 必填信息、地址、优惠券、备注、配送费和邮费、应付金额校验 |
| 模拟支付 | 成功、取消、失败；待支付重试、余额支付、防重复扣款与扣库存 |
| 订单 | 五种筛选、商品快照、金额、时间线、取餐码、演示物流、合法状态推进、再次购买 |
| 会员 | 演示登录与退出、普通会员/VIP、余额、积分、优惠券及流水 |
| 储值 | 充 100 赠 10、充 200 赠 30、充 500 赠 100，确认后模拟到账 |
| 权益 | 领券、使用门槛与范围说明、占用/释放/核销、积分兑换优惠券 |
| 地址 | 新增、编辑、删除、设置默认、选择返回结算 |
| 门店与重置 | 虚构门店详情、项目说明、二次确认恢复初始演示数据 |

所有履约、支付、会员身份、制作、物流、储值与积分都是**本地课程模拟**。没有真实收款、真实骑手、真实物流或商家后台。

## 目录

```text
小程序期末/
├─ project.config.json          微信开发者工具项目入口
├─ miniprogram/
│  ├─ app.js / app.json / app.wxss
│  ├─ pages/                    16 个原生页面
│  ├─ components/               三套首页、规格弹层、购物车弹层
│  ├─ services/api.js           商品、订单、支付、会员等业务规则
│  ├─ services/store.js         唯一持久化入口、版本化状态与原子提交
│  ├─ mock/                     商品、规格、账户、地址、订单及权益样例
│  ├─ utils/                    金额、输入校验与原生导航辅助
│  ├─ styles/                   统一色彩及基础样式
│  └─ assets/                   57 张本地 PNG 与素材来源说明
├─ scripts/                    原创素材生成、组件依赖验证、原生模板编译检查
├─ tests/                      业务、Page/Component 集成与组件加载回归测试
├─ docs/                       演示、规则、测试与限制
└─ artifacts/                  素材预览、测试/编译证据、原生工具诊断
```

三套首页组件分别为 `home-cat`、`home-cloud`、`home-dog`。底层购物车、商品、订单、地址和账户共享同一个业务服务，切换首页不会清空数据。

原创矢量绘制方式、PNG 映射及重新生成方法见 [素材说明](miniprogram/assets/README.md)。小程序实际加载本地 PNG；SVG 源稿位于 `scripts/asset-sources/`，不依赖小程序内 SVG 显示能力。细微纸纹由 `scripts/generate-paper.py` 使用固定种子生成，同步写入本地 PNG 和内嵌纹理 WXSS，不依赖外链。

## 演示数据与重置

初始包含 5 个分类、15 个商品（每类 3 个）、6 个可邮寄商品、1 个售罄商品、3 张已领取优惠券、2 个地址，以及待支付、进行中、已完成、已取消的样例订单。演示账户初始余额为 **120 元**、积分 **320**，已有相应期初、充值与消费流水。另有一张可现场领取的常规券和一种积分兑换券。

- 演示登录：「我的 → 演示登录」，无需真实手机号授权；不是生产身份认证。
- 风格切换：「我的 → 首页风格」，选择后点「回首页」；重新启动仍会保留。
- 重置：「我的」页底部「重置演示数据」，连续两次确认后恢复样例。此操作清除当前本地业务操作并恢复默认猫咪首页。
- 普通重新编译和重新打开不会主动覆盖已保存数据；清除开发者工具数据缓存会清除本地记录。

履约费用、服务区域、优惠券占用、库存、防重复和会员成长规则见 [业务规则](docs/BUSINESS_RULES.md)。

## 开发检查

需要 Node.js 18 或更高版本。测试不依赖第三方 npm 包：

```powershell
cd D:\大\小程序期末
npm test
npm run verify
```

当前测试包括业务规则、模拟 `wx` 环境中的原生 Page/Component 处理函数集成，以及组件完整文件、`component:true`、实际 `Component()` 注册、嵌套依赖和 WXML 别名检查。安装可选编译器后，还会检查三套首页编译后的分支、插画与点单入口。这些检查不替代开发者工具的真实组件加载、布局和真机测试。

可选：使用微信小程序编译器包附带的 `wcc/wcsc` 检查模板和样式：

```powershell
npm install --prefix tools-cache --no-audit --no-fund --ignore-scripts miniprogram-compiler@0.2.3
npm run compile:check
```

工具依赖仅在 `tools-cache/`，不进入 `miniprogram/`，不影响小程序运行。该包附带旧版编译器；检查结果写入 `artifacts/native-compile.json`，不等同于当前微信运行环境验收。

可选的原生截图脚本使用 `miniprogram-automator@0.13.0`。在正常启动并完成模拟器初始化的开发者工具中，重置本项目演示数据后可执行：

```powershell
npm install --prefix tools-cache --no-audit --no-fund --ignore-scripts miniprogram-automator@0.13.0
$env:WECHAT_DEVTOOLS = 'D:\大\文件\微信web开发者工具'
$env:WECHAT_AUTO_PORT = '29420'
node scripts/capture-native.js
```

其他电脑请将 `WECHAT_DEVTOOLS` 改为包含 `cli.js` 与 `node.exe` 的实际工具目录。脚本只连接本地原生模拟器、执行演示购买并保存截图，不上传或发布小程序。模拟器测试会改变本地演示数据。

本机旧版工具的自动化桥接曾出现逻辑上下文与可见模拟器视图不同步，自动页面查询和路由检查未通过。保留的失败自动化报告不代表成功验收；本轮原生视图结果以真实界面操作与截图为准，详见测试记录。
